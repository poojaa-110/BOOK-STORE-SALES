# 📚 Book Store Sales — SQL Data Analysis

## 📌 Project Overview

This project focuses on analyzing **bookstore data using SQL** to understand book performance, customer information, inventory, and time-based business data.

The project uses three main CSV tables:

- **Books** — Book details, authors, genres, prices, publication years, and stock.
- **Customer** — Customer demographics, segments, locations, activity status, and preferred channels.
- **Date** — Calendar and fiscal information such as year, quarter, month, week, and day.

The analysis uses SQL queries to extract meaningful business insights and support data-driven decision-making.

## 🎯 Business Objective

The objective is to analyze bookstore data to understand:

- Book and genre performance
- Author and book-level sales patterns
- Customer purchasing behavior
- Customer segments and locations
- Revenue and sales performance
- Inventory and stock levels
- Time-based sales patterns
- High-value and frequent customers


## 🔍 Key Analysis Areas

The SQL analysis covers:

- Books by genre and publication year
- Book prices and stock levels
- Total inventory
- Most and least expensive books
- Lowest-stock books
- Customer analysis
- Customer purchasing frequency
- High-value customers
- Revenue analysis
- Books sold by genre
- Best-selling books
- Author-level sales
- Fantasy book price analysis
- Sales by time period
- Remaining inventory after sales
